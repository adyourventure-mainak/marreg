# Routes

## Locale routes
- `/[locale]` → `app/[locale]/page.tsx`, public MARREG homepage
- `/[locale]/acts` → `app/[locale]/acts/page.tsx`, searchable five-Act finder
- `/[locale]/status` → `app/[locale]/status/page.tsx`, application status lookup
- `/[locale]/apply` → `app/[locale]/apply/page.tsx`, multi-step application preparation
- `/[locale]/offices` → `app/[locale]/offices/page.tsx`, Marriage Officer directory
- `/[locale]/help` → `app/[locale]/help/page.tsx`, public information hub
- `/[locale]/fees` → `app/[locale]/fees/page.tsx`, fee guide
- `/[locale]/objections` → `app/[locale]/objections/page.tsx`, corrections and objections
- `/[locale]/officer` → `app/[locale]/officer/page.tsx`, officer workspace
- `/[locale]/admin` → `app/[locale]/admin/page.tsx`, RGM administration workspace

## Standalone
- `/styleguide` → `app/styleguide/page.tsx`, token reference page
